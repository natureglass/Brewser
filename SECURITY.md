# Security Policy

Brewser takes the security of the runtime, the update mechanism, and the platform seriously — if you've found a vulnerability, we want to hear about it, responsibly.

## Reporting a vulnerability

Please report privately, as described in the **[Brewser security disclosure policy](https://docs.brewser.io/docs/support/security-disclosure)**. Do **not** open a public GitHub issue for a security vulnerability.

Include enough to reproduce the issue — what you did, what happened, and the impact — and allow reasonable time for a fix to ship before any public disclosure. Reports are acknowledged promptly.

## Scope

- The Brewser runtime and its handling of untrusted app code
- The self-update mechanism (signed, forward-only)
- The platform: submission pipeline, accounts, saves, and leaderboards

App-level bugs in an individual catalogue app are not vulnerabilities in Brewser itself — please report those as ordinary [bugs](https://github.com/natureglass/Brewser/issues).
