Learn more about Brewser and its features.

Brewser is a Nintendo Switch homebrew application that lets users discover, download, and run web-powered apps built with familiar technologies such as HTML, CSS, JavaScript, WebGL, and WASM.

The goal of Brewser is to make homebrew experimentation more approachable by giving developers a lighter way to build apps, tools, demos, and games using web technologies.

Nintendo Switch homebrew HTML CSS JavaScript WebGL WASM
What Brewser does Brewser acts as a browser-style runtime and app hub for web-powered homebrew experiences on Nintendo Switch.
For users Users can explore Featured, Community, and Experimental apps from inside Brewser, with permission prompts shown when needed.
For developers Developers can build apps using web technologies, test them locally, and submit them for possible inclusion in the Brewser app catalog.
App permissions Apps that request special access, such as storage or network usage, may ask the user to opt in before the app starts.

Libraries and frameworks

Brewser is built using homebrew and web runtime technologies. The project may use or integrate libraries and frameworks such as:

  • libnx Nintendo Switch homebrew development library.
  • SDL2 Cross-platform media/input layer used by many homebrew projects.
  • nx.js JavaScript/runtime integration for Switch-focused web app behavior.
  • HTML, CSS, JavaScript, WebGL, and WASM Web technologies used by Brewser apps and experiments.

Privacy note

Brewser may use network access to load websites, fetch app catalog information, or download app files when the user chooses to use those features.

Brewser itself does not intentionally collect personal information through this About page. Apps, websites, or third-party services opened through Brewser may have their own privacy practices, terms, cookies, analytics, or network behavior.

Users should review permission prompts carefully, especially for apps that request network access, storage access, WebGL, WASM, or other special capabilities.
