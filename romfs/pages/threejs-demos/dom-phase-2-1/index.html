DOM Phase 2.1 — text in non-canvas live elements

Validates that the live-overlay painter now draws textContent / innerHTML inside non-canvas position:fixed elements with the resolved font-family / font-size / color / text-align + synthesized bold (double-draw) + italic (0.2 rad shear). Static parser assertions render into the lower status canvas; visual paint tests appear as a vertical column of labelled bars on the right side of the screen, drawn over the page content as position:fixed overlays. Each bar's expected appearance is described in the status canvas — tally visual-vs-expected by eyeballing the column.


Visual check: 13 bars stack vertically along the right side of the screen (left=900, width=280). Each bar tests one text-rendering property. Bold should look noticeably thicker than plain (1-px-offset double-draw); italic should slant clearly to the right (0.2 rad column shear); colored text should match the labelled hex; clipped text (bar 11) should NOT spill outside the box.

Pre-authorized deviations from upstream: (1) Bold synthesized via 1-px-offset double-draw — nx.js's font parser rejects the bold prefix and falls back to a different (larger) font per [[nxjs-font-no-bold-italic]]. (2) Italic synthesized via 0.2 rad column shear — same parser issue with the italic prefix.
