DOM Phase 2.0 — element API foundation

Hand-rolled validation page for the Phase 2.0 generic element surface: classList, parentElement, insertBefore, replaceChild, toggleAttribute, textContent / innerHTML, getBoundingClientRect, nextSibling / previousSibling, ownerDocument, document.head, and the window-level mouse/touch event bridge that feeds drag handlers in M2.4+. Each check writes its result into the status canvas. Stats's tap-to-cycle panel is also instantiated to confirm Phase 1 + 1.5 don't regress.


Touch interactions to verify after the static checks above are green:
1. Tap the orange Stats panel (top-left of the page content area) — it should cycle FPS → MS → MB and the Stats tap cycle row above should flip green on first cycle.
2. Tap the cyan band fixed near top-right of the content area — it should toggle between dim and bright; the window mouse listener fired row above should flip green on first tap.
