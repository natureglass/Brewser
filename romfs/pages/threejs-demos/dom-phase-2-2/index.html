DOM Phase 2.2 — CSS cascade + pseudo-classes + pseudo-elements

Validates the M2.2 live-CSS engine: a <style> tag at runtime registers rules; selectors (tag, class, id, compound, descendant, child, attribute) match LiveElements; :active / :disabled / :checked / :empty / :not() pseudo-classes resolve; :before / :after pseudo-elements paint their content string; var(--name) resolves up the parent chain; @media (pointer:coarse) activates rules while @media (hover:hover) skips them. Visual bars on the right plus parser/match assertions in the lower status canvas.


The visual bars test cascade-driven styling: most bars have NO inline style — their background / color / bold / etc. come from the runtime <style> rules.

Interactive checks: tap Bar D (purple) — should brighten while held (cascade picks up :active rule). Tap Bar Q (the "I'm Q" bar near the bottom) — should toggle its data-skin attribute and flip backgrounds via the attribute-selector rule.

Pre-authorized deviations from upstream: none beyond the M2.2 surface limitations documented in swb-live-dom-phase-2-2: no + / ~ sibling combinators, no ::-webkit-* pseudo-elements, no @font-face (M2.6), no calc(), no :hover (touch device), no :nth-*.
