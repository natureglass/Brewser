DOM Phase 2.5 — scrollable container

Validates the M2.5 scrollable container: a position:fixed 300×400 panel containing 30 child rows (total content height ≫ container height). The panel has overflow-y:auto via the CSS cascade; touch-drag-swipe on it scrolls the contents.


Verify by swiping up on the panel — rows 1-16 should slide up to reveal rows 17-30. Tap a single row (no swipe) — it should report its number. The status row "current scrollTop (live)" should update during the swipe.
