DOM Phase 2.4 — form widgets

Validates form-widget painting + interaction: <input type=checkbox>, <button>, <input type=text> + type=number (both open the on-canvas keyboard on tap), <input type=color> (cycles a palette), <select> (cycles options on tap).


Tap each widget to verify. Text + number widgets open the on-canvas keyboard (the same one used by the URL bar) — type and Submit to commit, Cancel to abort. Disabled-attribute check is proven by the second checkbox that ignores taps.
