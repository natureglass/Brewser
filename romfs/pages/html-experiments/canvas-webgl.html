WebGL Experiments

A probe page for WebGL on inline canvases. Each <script> runs once at page parse time (no requestAnimationFrame / setTimeout); the OffscreenCanvas the runner allocated per <canvas> is then blitted into the layout slot by the painter.

How it works: nx.js's OffscreenCanvas only accepts a '2d' context, so inline <canvas> elements can't own their own WebGL context. The browser shell routes every inline getContext('webgl') call to the screen canvas's shared WebGL context (GPU bridge enabled), runs the script's draws into the bridge framebuffer, then reads the bridge back into the canvas's OffscreenCanvas so the painter blits the rendered pixels at the layout slot. State (programs, buffers, textures) is shared across scripts on the same page.

Each test pairs a render canvas (what the WebGL code drew, if anything) with a status canvas (what the script observed). Green text = success, orange = failure.
