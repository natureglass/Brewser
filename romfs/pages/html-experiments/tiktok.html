TikTok — end-to-end progressive MP4 playback

Demonstrates the full path for a real-world HTTPS video: inline script fetches the TikTok embed page over HTTPS, regex-extracts the inline source URL from the response HTML, and hands that URL to a real video element. libavformat's https protocol (TLS backend = libnx) decodes the H.264 / AAC stream directly from the CDN with no disk roundtrip.

2. Player

Once extraction completes, the video element below picks up the extracted CDN URL via the .src property + .load(). Tap the play triangle to open the decoder. Tap the frame itself to enter fullscreen; gamepad B exits.

Caveats: TikTok rotates its CDN URLs every few hours (the embed page signs each one with a short expiry), so a refresh of this page also re-extracts the URL. The hard-coded video ID below is a public test clip with no DRM. YouTube embeds are unsupportable on this runtime — see the reference-swb-youtube-embed-blocker note for why.
