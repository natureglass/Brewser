1. HTTPS to Cloudflare DNS — https://one.one.one.one/

Tests TLS + DNS + socket against a minimal hostname target. Using one.one.one.one instead of 1.1.1.1 avoids the mbedtls iPAddress-SAN matching limitation that makes raw-IP HTTPS targets fail with a generic X509 verify error even when the chain is trusted.

2. HTTP to IP — http://1.1.1.1/

Tests bare socket without TLS. If this works but HTTPS to IP fails, TLS is the problem.

3. HTTPS to hostname — https://example.com/

Tests DNS + TLS + socket end-to-end.

4. HTTP to hostname — http://example.com/

Tests DNS + socket without TLS.

5. romfs control — romfs:/main.js

Bypasses the socket layer entirely; should always succeed. If even this fails, the runtime fetch wrapper itself is broken.
