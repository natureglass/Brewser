About switch-web-browser

Switch homebrew browser shell built on @switch-web/runtime. Sibling to switch-webapp-player; both consume the same runtime layer.

Status: minimal scaffold + working BrowserResourceLoader. HTML pipeline supports a focused subset of CSS (selectors, inheritance, text-align, line-height, list-style, borders, display: none), inline scripts that draw into <canvas> offscreens, and HTML <button data-action> for shell-level toggles.

Try the test pages

  • Web Pages Demos — index of HTML, CSS, canvas, and WebGL pipeline fixtures
  • WebGL Experiments — Khronos conformance suites + Three.js r162 demos via the GPU bridge
  • network — diagnose HTTPS / HTTP / DNS / socket layers

Controls

  • ZR or tap the URL bar — navigate
  • B back  ·  X forward  ·  Y reload
  • L + R — exit fullscreen
  • Hold L + R + − for ~1 second — exit the shell
