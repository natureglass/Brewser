Web Experiments

Fixtures for the HTML, CSS, canvas, and WebGL paths. Each link below opens a self-contained page that exercises one part of the rendering pipeline.

DOM tests

Live-DOM (script-driven) reference pages that exercise the Phase 2 DOM surface end-to-end with canonical patterns: class-based CSS cascade, position:fixed via cascade, :root custom properties consumed via var(), flex column → flex row nested layout, one of each form widget, event bubbling, scrollable containers. The reference page is the baseline that should be solid before dropping in any third-party DOM-based library.

  • dom-reference
    Comprehensive scripted page with a Settings panel (one of each form widget) + a Scrollable list. Exercises class-based cascade positioning, var() resolution, flex layout, form widget tap + keyboard, 3-level event bubbling, and scroll-drag-vs-tap.
  • dom-elements
    DOM Elements showcase: every supported HTML element + every CSS feature in one scrollable panel.

DOM Phase Validation

Hand-rolled validation pages for the DOM build-out (post-platform-hardening Phase 2 series). Each page exercises one slice of the live-DOM surface so a Citron run pins the new primitives end-to-end before the next slice lands. The eventual phase 2.6 milestone is a drop-in lil-gui port.

  • DOM Phase 2.0 — element APIs
    M2.0: classList, parentElement, insertBefore, replaceChild, toggleAttribute, textContent / innerHTML, getBoundingClientRect, sibling getters, document.head, and the window-level mouse/touch event bridge for M2.4+ drag handlers. Includes a Stats coexistence test to guard Phase 1 + 1.5.
  • DOM Phase 2.1 — text in non-canvas elements
    M2.1: live-overlay painter draws textContent/innerHTML in non-canvas position:fixed elements with resolved font-size / font-family / color / text-align + synthesized bold (1-px-offset double-draw) + italic (0.2 rad shear). Per nxjs-font-no-bold-italic the canvas font string omits the bold/italic prefix to avoid nx.js's parser fallback. 13 visual bars + 19 parser assertions + tap regression.
  • DOM Phase 2.2 — CSS cascade + pseudo-classes + pseudo-elements
    M2.2: runtime <style> rules registered with the live-css cascade (powered by css-tree); selectors (tag/class/id/compound/descendant/child/list/attribute), pseudo-classes (:active/:disabled/:checked/:empty/:not(); :hover always false on touch), pseudo-elements (:before/:after with content), var() + custom-prop inheritance, @media (pointer:coarse) applies + (hover:hover) skipped, classList/attr changes invalidate computed-style cache. 16 visual bars + 25 assertions + tap-driven :active + attribute-toggle Bar Q.
  • DOM Phase 2.3 — flex + block layout
    M2.3: new scripts/live-layout.ts runs a layout pass before paint. Block + flex column/row + flex-grow distribute + padding/margin/gap + min/max/box-sizing + alignItems/justifyContent. getBoundingClientRect + hit-test now read the layout cache. 6 visual panels + 20 assertions.
  • DOM Phase 2.4 — form widgets
    M2.4: form-widget painters for <input type=checkbox|button|text|number|color> + <button> + <select>. Tap dispatches checkbox toggle, button click, async KeyboardOverlay open for text/number, color palette cycle, select option cycle. .value / .checked getters/setters on LiveElement. disabled attribute blocks taps. 6 widgets + 13 assertions.
  • DOM Phase 2.5 — scrollable container
    M2.5: overflow-y:auto + touch-drag-scroll. Container with intrinsic content > clientHeight becomes scrollable; vertical-swipe gestures inside it update scrollTop; tap (no drag) still fires click. LiveElement exposes scrollTop / scrollHeight / clientHeight. 30-row test panel + scroll-drag + tap-vs-swipe discrimination.
  • DOM Phase 2.6 — lil-gui drop-in
    M2.6 (final Phase 2 slice): upstream lil-gui 0.17 wrapped as IIFE with build-time CSS patches (icon glyph substitution + width-percent → flex). One of each controller type (slider, number, string, boolean, color, option, function, folder) + Stats coexistence regression. End-to-end test of the entire M2.0–M2.5 surface.

    Per-paragraph leading and how line height interacts with mixed font sizes.

    Bullet markers, numbered lists, and nested list rendering.
  • border
    Border drawing with mixed widths, styles, and per-side colors.
  • widgets
    <details> / <summary> / <meter> / <progress> rendering — tap summaries to toggle.
  • tables
    Auto-width <table> layout with <thead>/<tbody>/<tfoot>, <caption>, per-cell styling, and inline content in cells.
  • svg
    Inline <svg> with <rect>/<circle>/<ellipse>/<line>/<polyline>/<polygon>/<path>, viewBox scaling, and <g> attr inheritance.

Canvas

  • canvas-script
    Multiple inline <script> blocks drawing 2D primitives into per-canvas offscreens.

  • canvas-webgl
    Probes WebGL on inline canvases — context acquisition, GL info dump, clear() round-trip, and a solid-color triangle with center-pixel verification.
