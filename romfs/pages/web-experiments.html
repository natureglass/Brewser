HTML parser & layout

  • two
    A second page used to test back / forward navigation between fixtures.
  • images
    Block + inline <img> rendering, alt-text placeholders, and image sizing.
  • pre
    Whitespace preservation inside <pre> and inline <code>.
  • benchmark
    Scroll-tick + repaint timings for the live-DOM content pipeline. Scroll for ~5s then reload (Y) to render the captured stats.

CSS

  • css
    Cascade, specificity, inline styles, margin, padding, and background colors.
  • external-css
    Loading and applying a stylesheet referenced via <link rel="stylesheet">.
  • inherit
    Font-size and color inheritance down the DOM tree.
  • selectors
    Type, class, id, descendant, and pseudo-class selector matching.
  • align
    Horizontal alignment via text-align across left, right, center.
  • display-none
    Hiding elements with display: none and removing them from layout flow.
  • line-height
    Per-paragraph leading and how line height interacts with mixed font sizes.
  • list-style
    Bullet markers, numbered lists, and nested list rendering.
  • border
    Border drawing with mixed widths, styles, and per-side colors.
  • widgets
    <details> / <summary> / <meter> / <progress> rendering — tap summaries to toggle.
  • tables
    Auto-width <table> layout with <thead>/<tbody>/<tfoot>, <caption>, per-cell styling, and inline content in cells.
  • svg
    Inline <svg> with <rect>/<circle>/<ellipse>/<line>/<polyline>/<polygon>/<path>, viewBox scaling, and <g> attr inheritance.
  • rounded
    Rounded backgrounds + borders via border-radius, plus clip-to-rounded for <img> and <canvas>. Supports px values and % (50% ⇒ circle).
  • video
    Slice 1 (this build): <video> element layout + placeholder paint. Reserves the attribute-declared box and shows the resolved source URL with a play triangle. Actual NVDEC playback lands in a future slice.

Canvas

  • canvas
    Placeholder rendering for a <canvas> with no script — confirms layout reserves the right slot.
  • canvas-script
    Multiple inline <script> blocks drawing 2D primitives into per-canvas offscreens.
  • canvas-responsive
    Fullscreen-canvas mode demo — re-runs the script when the canvas is resized to fill the viewport.
  • canvas-webgl
    Probes WebGL on inline canvases — context acquisition, GL info dump, clear() round-trip, and a solid-color triangle with center-pixel verification.

Networking & async

  • async-fetch
    Inline <script> that awaits a fetch and draws the response into a canvas — exercises the async-script path.
