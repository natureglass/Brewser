SwitchSurf Player Open the built-in player experience. SwitchSurf Experiments Try demos, tests, and creative browser experiments. Library options Open bookmarks, history, and saved browsing items.

Controls

  • ZR — open the URL bar
  • B / X — back / forward
  • Y — reload
  • L + R — exit any fullscreen mode
  • Hold L + R + − for ~1 second — exit the shell
