<canvas> layout

Validates that every <canvas> reserves its declared attribute size in the page flow even without a script drawing into it. The slot stays at the declared dimensions so surrounding content lays out the same as on a real browser. Page scripts ARE executed on brewser:// pages; this fixture intentionally omits one so the empty-slot case is exercised.
