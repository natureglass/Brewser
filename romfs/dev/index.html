Performance audits

  • perf-image-stress
    Phase 0 audit for the parallel-processing milestone. Loads 30 PNGs in parallel via new Image(), times each from src-assign to onload, writes per-image + summary stats to logs/perf-image-stress.log. Phase 0 result: decode is already parallel (~21/30 parallelism factor) — Phase 1+2 of the milestone obsolete.
  • perf-latency-probe
    Phase 0.5 follow-up. Runs 7 tests back-to-back varying N (1, 10, 30, 60), load mode (parallel Image, serial Image, parallel fetch, sync readFileSync), then writes a structured report with interpretation hints to logs/perf-latency-probe.log. Use to narrow down the ~520 ms fixed-latency tax found in Phase 0 (Cairo vs onload-dispatch vs FS-serial).
  • perf-img-dom-stress
    Phase 4 verification. Loads 30 <img> tags via live-DOM (the path Phase 4 coalesces — the other two perf pages use page-side new Image() which bypasses live-DOM entirely). Measures rAF cadence in early (decode active) vs late (idle) windows; writes ratio + verdict to logs/perf-img-dom-stress.log. Phase 4 win = early max gap close to late max gap.

Game demos

  • demo-breakout
    Brick-breaker game built on the just-shipped Web API stack — Canvas 2D + Web Audio (per-event tone synthesis) + localStorage (high score) + @keyframes (animated title) + @font-face + tap input. Heavy log instrumentation at logs/demo-breakout.log for debugging. Tap the play area to position the paddle + launch the ball.

API surface audit

  • api-probe
    Detects which Web APIs the runtime exposes (Web Audio, localStorage persistence, CSS @keyframes, @font-face, Pointer Lock, WebSocket, IndexedDB, Web Crypto, MessageChannel, File API) and exercises each with a small functional sub-test. Auto-runs on load; logs structured results to logs/api-probe.log. Scoping data for the itch.io browser-games milestone.
  • web-audio-tone
    Tier-1 Web Audio API verification. Plays audible test tones via the JS-side AudioContext/OscillatorNode/GainNode/AudioBufferSourceNode/decodeAudioData wrappers added in nxjs-source/packages/runtime/src/web-audio.ts on top of the existing 24-voice audrv mixer. Turn volume up before running; logs to logs/web-audio-tone.log.
  • workers-tier0
    Tier-0 Web Workers foundation test. Spawns a real OS-thread Worker with its own JSRuntime+JSContext, exchanges bidirectional postMessage(string), runs a 100-round-trip stress loop, validates a parallel compute:N result. No structured clone yet (Tier-1). Pass = foundation viable for full Worker support; failure = reconsider the milestone. Logs to logs/workers-tier0.log + per-worker logs/worker-N.log.

Networking & async

  • async-fetch
    Inline <script> that awaits a fetch and draws the response into a canvas — exercises the async-script path.
  • tiktok
    End-to-end real-world HTTPS video: inline script fetches a TikTok embed page, regex-extracts the progressive MP4 URL from the inline <video src>, and hands it to a <video> element. Decoded directly from the CDN by libavformat's https protocol (libnx TLS backend) — no disk roundtrip.
