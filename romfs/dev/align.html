Centered heading

This paragraph is left-aligned (the default). It exists to anchor the eye while you compare it against the alignment variants below.

Right-aligned: this whole paragraph hugs the right edge. Wrapping happens normally; the trailing slack of each line is moved to the left side.

Centered paragraph. Each line is individually centered within the content box, so the line breaks the layout chose look symmetric around the middle.

Justified paragraph: every non-final line is stretched to fill the full content width by widening the inter-word spaces. The last line stays left-aligned so a short trailing run doesn't get visually shredded. The longer this paragraph runs, the more lines you'll see participating in the justification, which makes the effect easier to spot.

Inherited center: this div sets text-align: center, and these paragraphs pick it up via inheritance.

Direct override: this paragraph has its own text-align: left rule, so it wins over the inherited center despite the descendant selector being more specific.
